How this page gets here

  1. A push to the qa branch runs GitHub Actions: validate the site, build a Docker image, and smoke-test it.
  2. The tested image is pushed to Docker Hub as :qa, and the server deploys it to QA automatically.
  3. Merging qa into main publishes :prod, and production updates the same way.
